# 招聘表单通用适配（2026-10-16）

本轮按控件结构修复，不依赖公司域名、个人账号或特定职位链接。

## 覆盖范围

| 场景 | 行为 |
| --- | --- |
| 简历解析后显示只读卡片 | 识别阶段不点按钮；选择资料库后打开明确的基本信息/教育/工作/校园/项目编辑入口，再扫描填写。 |
| 工作职责标签绑在外层组件 | 继承单字段容器的 `label[for]` / `data-label`，跳过字数计数和编辑工具栏。 |
| 卡片标题是公司或项目名称 | 优先使用经历板块标题，避免公司标题遮住字段归属。 |
| 富文本职责 | 使用浏览器编辑命令通知编辑器；多行文本转义后写入，保留换行，拒绝编辑时保留内部节点。 |
| 多段经历部分缺栏或只打开后面一段 | 富文本参与分组；明确卡片按原始兄弟顺序取资料，包含未打开的只读卡片。 |
| 日期拆成年/月/日 | 识别日期父标签与组成部分，按可见数字/中文/英文月份选项取值，同一日期不轮转成多段经历。 |
| 起止日期共享范围标签 | 分别识别开始和结束端点。复杂日历的具体写入仍由现有日期适配器处理。 |
| 日期缺某个部分或没有对应选项 | 保留整组原值，不编造日或只覆盖其中一部分。 |
| 原生多选 | 按资料库完整覆盖，选项缺失/锁定时不做部分覆盖；撤销恢复原选项。 |
| 后续字段触发页面回滚 | 整批填写后再次回读，已回滚或重建的字段改报失败。 |

## 边界

- 只点击明确且位于对应资料板块的编辑/添加入口，不点击提交、保存、删除或页面跳转链接。
- 网站切换编辑会关闭上一段时，停止继续切换，按当前卡片的原序号填资料并提示逐段处理。每轮最多打开 20 段。
- 不自动绕过禁用、登录、验证码和封闭组件；资料库没有相应内容时保留网页原值。
- “原生 / Ant 风格 / Element 风格 / 自研布局”测试使用合成 DOM 与编辑器状态模型，不等同于所有使用这些框架的真实招聘站都已实测。百亚登录后的真实页面尚未验证。
