# 招聘表单动态控件修复（2026-10-16）

延续通用结构适配，修复覆盖和撤销中的动态变化，不绑定招聘网站域名。

| 场景 | 本轮处理 |
| --- | --- |
| 输入后网页重建控件 | 在原包装仍存在、身份属性与位置一致时重新定位，支持继续覆盖和撤销；原包装消失或字段身份不明确时停止猜测。 |
| 年份、月份使用只读自定义下拉 | 按拆分日期识别；月份数字可匹配 `06月`、`June` 等选项，不将完整日期写进月份。可见标签优先于冲突的内部 ID。 |
| 改年份后月份选项发生变化 | 填写前记录整组原值；任一部分失败时恢复整组，并核对恢复结果。网页拒绝恢复时明确提示。 |
| 视觉单选/多选隐藏原生输入 | 有可见关联标签时识别；忽略隐藏模板与禁用项，避免首项禁用导致整个组漏扫。 |
| 语言能力多选没有统一 name | 在明确带题目的 fieldset/group 内合并选项；无名独立协议勾选仍不进入扫描。 |
| 网站拒绝点击 | 不强改 checked 伪造成功；多选中途失败时尝试恢复原选择，并核对是否恢复完成。 |
| 同一富文本内部还有可编辑节点 | 只扫描根编辑器，跳过 aria-readonly 编辑器，避免重复写入。 |
| 当前正在编辑后面的经历 | 保留当前编辑卡片及其原始序号，不为补齐前面卡片而切走。 |
| 恢复日期、撤销导致其他字段联动 | 最后重新核对整批结果，按真实回显计算成功数量。空多选撤销使用真实点击通知页面。 |
| 异常填写计划 | 在任何写入前检查全部字段类型，拒绝格式无效的整份计划。 |
