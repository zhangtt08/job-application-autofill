# 跨站表单兼容修复（2026-10-16）

## 本次修复

- 扫描、字段定位、下拉选项和撤销递归访问多层开放 Shadow DOM；组件内的标签、板块标题和外部登录语境保持有效。
- 输入事件穿过 Shadow DOM 通知页面，避免只改变显示值而没有更新页面监听的状态。
- 可搜索下拉识别内部输入框，读取实际选中项；支持 Ant 无障碍列表与可见虚拟列表分离的结构，以及 react-select 的选中值显示。
- 下拉优先使用 `aria-controls` / `aria-owns` 关联自己的弹层；等待目标选项加载，跳过禁用和隐藏选项。同名候选无法消歧时停止，不点其他下拉。
- 写入策略失败时，即使搜索框出现目标文字，也不能判定填写成功。重试统一由验证层负责，避免多层重复点击。
- 原生 `date` / `month` 接受资料库中的点号、中文年月等格式并转换为 HTML 格式；日期不完整或无效时保留网页原值，不补造日期。
- 自动补齐经历时重新获取被页面重建的板块；最后一次新增后添加按钮消失也能记录结果。补充英文教育/工作/项目添加按钮和尾部加号识别。
- 排除隐藏祖先、inert、禁用 fieldset 和 aria 禁用控件；扫描稳定判定检查节点替换，并始终遵守等待上限。
