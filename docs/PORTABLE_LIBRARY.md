# 资料库迁移实现与验收

## 实现

- `src/profile/libraryStore.ts`：迁移用严格整库校验、仅空存储恢复 `profile-library.local.json`、恢复前重新检查现有数据；有效正式资料存在时清理已知历史备份键。
- `src/profile/portable.ts`：使用浏览器标准 API 生成 UTF-8 ZIP，逐文件核验读取结果；保存全部资料库与当前选库，保留可再次导出的文件清单。
- `scripts/portable-files.mjs`：完整构建结束后登记扩展文件，排除个人旧更新脚本与补丁。
- 资料页“更多”提供“保存迁移包”，延迟加载打包代码，导出包含当前草稿，错误可见。
- 随包个人资料和现成 ZIP 仅保留本机，已加入 Git 忽略；常规浏览器测试移除个人随包文件，使用合成资料。

## 验收范围

1. 全部资料库、公共信息、当前库和旧版镜像正确恢复。
2. 已有有效、空白、旧版及异常数据均不被随包文件直接替换；读取文件期间新写入的资料保留。
3. 迁移文件损坏、库 ID 重复、选库不存在、库内容无效时整份拒绝。
4. ZIP 完整解压并通过 CRC 校验，新用户目录加载真实 MV3 扩展；修改后再次打包仍可用。
5. 未保存草稿包含在迁移包中；其他库保持原内容。
6. API Key、投递历史、浏览器备份不出现在新浏览器中，原电脑模型设置保留。
7. 清理仅命中旧备份键与项目 `资料库导入` 下明确的备份目录/导入前快照，正式资料不受影响。
